# Bundled fonts

Outfit, JetBrains Mono, and Noto Sans SC are bundled unchanged from Google Fonts. Each family is licensed under the SIL Open Font License 1.1; the upstream license text is included beside each family under this directory.

Upstream sources:

- Outfit: https://github.com/google/fonts/tree/main/ofl/outfit
- JetBrains Mono: https://github.com/google/fonts/tree/main/ofl/jetbrainsmono
- Noto Sans SC: https://github.com/google/fonts/tree/main/ofl/notosanssc
